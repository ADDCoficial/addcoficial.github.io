# ⛪ Assembleia de Deus Discípulos de Cristo (ADDC)

Este é o repositório do site oficial da **Assembleia de Deus Discípulos de Cristo (ADDC)**. O projeto foi desenvolvido para fornecer informações sobre a igreja, programação de cultos, eventos e localização para toda a comunidade.

---

## 🌐 Site Online

O site pode ser acedido através do link:
👉 **[https://addcoficial.github.io/Site-me/](https://addcoficial.github.io)**

---

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estruturação do conteúdo
- **CSS3** - Estilização e design responsivo
- **Git & GitHub** - Controlo de versão e hospedagem

---

## 📂 Estrutura do Projeto

- `index.html` — Página principal do site.
- `style.css` — Estilos e formatação visual.
- `logo.jpeg` — Logótipo da igreja.
- `arquivos.json` — Configurações do projeto.

---

## 💻 Como Atualizar o Projeto

Para atualizar o site na sua máquina e enviar as alterações para o GitHub:

1. Guarde as alterações nos ficheiros no VS Code.
2. No terminal, execute:
   ```bash
   git add .
   git commit -m "Atualização do conteúdo do site"
   git push origin main
